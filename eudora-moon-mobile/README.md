# Eudora Moon mobile

Standalone Expo application for Eudora Moon. It uses the shared Eudora backend's native token endpoints and published-story APIs; it has no Academic app-shell, course, assessment, or payment dependency.

Copy `.env.example` to `.env`, set `EXPO_PUBLIC_API_URL` for the device/simulator, install dependencies with `pnpm install`, then run `pnpm start`.
